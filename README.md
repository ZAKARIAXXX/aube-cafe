# Aube Café Template

A modern, minimalistic website for a specialty coffee shop called "Aube Café" in Rabat, Morocco. All site content in French and Darija.

## Features & Design
- **Warm Minimalism**: Cream/ivory background, deep espresso brown text, terracotta accent, and WhatsApp green CTA.
- **Typography & Layout**: Serif typography for headings, clean sans-serif for body text, generous whitespace, and smooth scroll reveal animations.
- **Single-page navigation**:
  1. **Navbar**: Logo "Aube", smooth links (Accueil, Menu, Notre histoire, Galerie, Contact), language toggle (FR / Darija), and WhatsApp "Commander" button.
  2. **Hero**: Full-screen hero with striking coffee photography, headline "Le café, élevé au rang d’art.", subtext, and CTAs (Voir le menu / Nous trouver).
  3. **Marquee strip**: Infinite marquee scrolling bar.
  4. **Notre histoire**: Story section with stats.
  5. **Menu**: Categorized menu with prices in MAD.
  6. **Galerie**: Editorial photo grid.
  7. **Infos pratiques**: Address in Agdal, Rabat, opening hours, phone number, and direct WhatsApp contact button.
  8. **Footer**: Clean footer with social links.

## Local Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

Ready for deployment on **Vercel** with zero extra setup.
